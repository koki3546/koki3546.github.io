About KOKI

Everything you need to know about the KOKI project.

What is KOKI?

KOKI is a story-driven meme token on the Base blockchain. The project is inspired by an original pirate elephant character whose adventures explore courage, friendship, and freedom.

KOKI combines creative storytelling with a blockchain-based token project.

What makes KOKI different?

KOKI is built around an original fictional universe rather than only a meme image. The KOKI Chronicles feature an ongoing adventure with recurring characters and connected storylines.

Season One contains twelve chapters. Future stories are planned.

Is KOKI a utility token?

KOKI is currently presented as a meme token and creative project. No specific token utility, income entitlement, or financial return is promised.

Any future features would be announced through official project channels.

Is KOKI liquidity locked?

No. The liquidity provider tokens were not locked at launch.

The creator held the liquidity provider position at launch and could withdraw liquidity.

Liquidity removal may make trading difficult or impossible. There is no guaranteed liquidity lock or minimum liquidity period.

Why does Uniswap show an impersonation warning?

During a trading quote review, Uniswap displayed an impersonation warning for KOKI provided through Blockaid's security screening.

The exact reason for this classification has not been independently established. The warning should not be assumed to be either correct or incorrect without further review.

A review request was submitted to Blockaid on October 23, 2026. Submission does not mean the warning has been removed or the token has passed a security review.

Users should not ignore security warnings solely because a project disputes them. Verify the contract independently and consider the risks carefully.

Has KOKI been security audited?

No independent security audit has been completed or claimed.

A verified contract on BaseScan allows users to inspect published code, but verification is not equivalent to a security audit.

Why can small trades affect the price?

KOKI's initial liquidity pool was very small.

Automated market maker pools adjust token prices according to the pool's token balances. Even relatively small trades can create significant price impact when liquidity is limited.

Slippage, transaction fees, and changing pool balances can affect the final amount received.

Safety & Risks

Important information before interacting with any cryptocurrency.

Is KOKI an investment?

KOKI is a meme token and creative project. It does not guarantee profits, token price appreciation, or financial returns.

Cryptocurrency assets are speculative and may lose their entire value. Nothing on this website constitutes financial advice.

What are the main risks of KOKI?

Key risks include limited liquidity, substantial price volatility, slippage, liquidity withdrawal, smart contract vulnerabilities, and the possible loss of the entire token value.

A large portion of the token supply remained in the creator's wallet immediately after launch. Concentrated token ownership can create additional market risks.

KOKI has not undergone an independent security audit, and a security screening warning has been reported.

How can I avoid scams?

Use only links published on the official KOKI website. Independently verify the Base contract address before interacting with a token or trading platform.

Never share your wallet recovery phrase, seed phrase, or private key with anyone. Be cautious of impersonators, fake giveaways, and unsolicited messages.

Do not bypass a security warning without understanding the risk.
