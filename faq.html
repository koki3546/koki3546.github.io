About KOKI

Everything you need to know about the KOKI project.

What is KOKI?

KOKI is a story-driven meme token on the Base blockchain. The project is inspired by an original pirate elephant character whose adventures explore courage, friendship, and freedom.

KOKI combines creative storytelling with a blockchain-based token project.

What makes KOKI different?

KOKI is built around an original fictional universe rather than only a meme image. The KOKI Chronicles feature an ongoing adventure with recurring characters and connected storylines.

Season One contains twelve chapters. Future stories are planned.
